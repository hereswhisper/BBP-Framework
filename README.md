# BBP-Framework

This is just a fun little unity project recreating some stuff from **Baldi's Basics Plus** and **Baldi's Basics Classic Remastered**.

This is a fan-made project built for learning and experimenting. We are not affiliated with Basically Games.

## About

BBP-Framework's goal is to recreate some mechanics, systems and structures found in Baldi's Basics Plus and Baldi's Basics Classic Remastered and is purely a personal/educational project.

# NOTICE
This repo does NOT contain any textures, assets or other copyrighted assets from Baldi's Basics Plus.

To use the Baldi's Basics Plus specific textures you must:
1. Own a legitimate copy of "Baldi's Basics Plus"
2. Extract the textures from your own copy
3. Place them into the "BBP Textures" folder in assets (DO NOT REPLACE THE METAs... JUST THE PNG)

No assets from Baldi's Basics Plus will be provided or distributed with this project.
