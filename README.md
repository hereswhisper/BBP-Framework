# BBP-Framework

This is just a fun little unity project recreating some stuff from **Baldi's Basics Plus** and **Baldi's Basics Classic Remastered**.

This is a fan-made project built for learning and experimenting. We are not affiliated with Basically Games.

## About

BBP-Framework's goal is to recreate some mechanics, systems and structures found in Baldi's Basics Plus and Baldi's Basics Classic Remastered and is purely a personal/educational project.
